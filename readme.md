# Jacob Sweeten's portfolio

Personal portfolio built with React and Vite, deployed to GitHub Pages.

## Local development

```sh
npm install
npm run dev
```

## Build and preview

```sh
npm run build
npm run preview
```

The production site is written to `dist/`. The GitHub Actions workflow builds and deploys it to GitHub Pages whenever changes are pushed to `main`. The custom domain is preserved through `public/CNAME`.
